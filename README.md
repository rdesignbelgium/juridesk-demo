# Juridesk — démo

Interface de travail pour les métiers du droit en Belgique (avocats, juristes, huissiers, notaires).
Démo statique : dossiers, atelier de rédaction guidé avec aperçu en direct FR/NL, calculateur de créance, signatures & envois, espace clients.

Données fictives — aucun conseil juridique. Les taux affichés sont des valeurs de démonstration.

## Lancer en local

Ouvrir `index.html` dans un navigateur (aucun build, aucune dépendance).

## Déploiement

GitHub Pages, branche `main`, racine du dépôt.
